## 🔧 故障排除

### 常见问题

#### 1. 字体警告
**问题：** `UserWarning: Glyph missing from font(s) Arial`
**解决：** 这是中文字体警告，不影响功能，图表仍会正常生成

#### 2. OpenMP警告
**问题：** `OMP: Hint This means that multiple copies of the OpenMP runtime`
**解决：** 设置环境变量 `KMP_DUPLICATE_LIB_OK=TRUE`

#### 3. GPU监控失败
**问题：** `ModuleNotFoundError: pynvml`
**解决：** 脚本会自动降级到基础GPU监控，或安装 `pip install pynvml`

#### 4. 图表不显示
**问题：** 无GUI环境下图表无法显示
**解决：** 图表会自动保存为PNG文件，查看输出目录

## 📈 性能优化建议

### 1. 硬件配置
- **GPU训练：** 推荐使用CUDA兼容的GPU
- **内存：** 建议16GB以上系统内存
- **存储：** SSD硬盘提升I/O性能

### 2. 训练参数调优
- **批次大小：** 根据GPU内存调整
- **学习率：** 使用学习率调度器
- **可视化频率：** 降低绘图频率提升性能

### 3. 监控优化
- **日志级别：** 生产环境使用WARNING级别
- **保存频率：** 减少检查点保存频率
- **图表分辨率：** 根据需要调整DPI

## 🎨 自定义可视化

### 添加新的图表类型

```python
def generate_custom_plot(self):
    """自定义图表生成"""
    plt.figure(figsize=(10, 6))
    
    # 你的绘图代码
    plt.plot(self.metrics['epochs'], self.metrics['custom_metric'])
    plt.title('自定义指标')
    plt.xlabel('Epoch')
    plt.ylabel('Custom Metric')
    
    # 保存图表
    plot_path = self.save_dir / 'plots' / 'custom_plot.png'
    plt.savefig(plot_path, dpi=300, bbox_inches='tight')
    plt.close()
```
