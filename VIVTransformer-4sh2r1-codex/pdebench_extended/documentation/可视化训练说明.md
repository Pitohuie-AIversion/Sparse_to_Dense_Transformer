# 🎯 压力场重建训练 - 可视化功能说明

本项目提供了完整的可视化训练功能，让您可以实时监控训练过程，包括损失曲线、硬件使用情况、预测结果对比等。

## 📋 功能特性

### 🔥 实时可视化
- **损失曲线**: 实时显示训练损失、验证损失和测试损失
- **硬件监控**: GPU使用率、内存使用率实时图表
- **学习率变化**: 学习率调度的可视化
- **预测对比**: 实时显示模型预测结果与真实标签的对比

### 📊 TensorBoard集成
- 完整的训练指标记录
- 硬件使用情况监控
- 模型结构可视化
- 支持远程访问

### 💾 自动保存
- 训练过程中的所有图表自动保存
- 完整的训练报告生成
- 硬件监控日志记录

## 🚀 快速开始

### 方法1: 双击启动（推荐）

1. 双击 `启动可视化训练.bat` 文件
2. 程序会自动检查环境并启动训练
3. 实时可视化窗口会自动打开

### 方法2: 命令行启动

```bash
# 基本启动
python run_training_with_vis.py

# 使用自定义配置
python run_training_with_vis.py --config your_config.yaml

# 禁用实时可视化窗口（仅使用TensorBoard）
python run_training_with_vis.py --no-realtime-vis

# 禁用TensorBoard
python run_training_with_vis.py --no-tensorboard

# 自定义TensorBoard端口
python run_training_with_vis.py --tensorboard-port 8080
```

### 方法3: 直接调用训练脚本

```bash
# 完整功能启动
python train_with_visualization.py --config configs/pressure_field_training.yaml

# 禁用实时可视化
python train_with_visualization.py --config configs/pressure_field_training.yaml --no-realtime-vis
```

## 🖥️ 可视化界面说明

### 实时可视化窗口
训练开始后会打开一个包含多个子图的窗口：

1. **顶部**: 训练损失曲线（训练/验证/测试损失）
2. **中间左**: GPU使用率实时图表
3. **中间中**: 内存使用率实时图表
4. **中间右**: 学习率变化曲线
5. **底部**: 预测结果对比（目标 vs 预测）

### TensorBoard界面
- 自动启动在 `http://localhost:6006`
- 包含完整的训练指标
- 支持多次训练结果对比

## 🔧 配置说明

### 可视化配置
```yaml
visualization:
  enabled: true              # 启用可视化
  save_interval: 5           # 保存间隔（epoch）
  plot_types:                # 绘图类型
    - loss_curves
    - hardware_usage
    - prediction_comparison
```

### 硬件监控配置
```yaml
hardware_monitoring:
  enabled: true              # 启用硬件监控
  interval: 1.0             # 监控间隔（秒）
  log_gpu: true             # 记录GPU使用
  log_memory: true          # 记录内存使用
  log_cpu: true             # 记录CPU使用
```

## 🐛 常见问题

### Q: 实时可视化窗口不显示
**A**: 检查以下几点：
- 确保安装了matplotlib和相关GUI后端
- 在远程服务器上运行时，使用 `--no-realtime-vis` 参数
- 检查是否有图形界面支持

### Q: TensorBoard无法访问
**A**: 检查以下几点：
- 确保端口6006未被占用
- 使用 `--tensorboard-port` 指定其他端口
- 检查防火墙设置

### Q: GPU监控显示为0
**A**: 检查以下几点：
- 确保安装了CUDA和PyTorch GPU版本
- 检查GPU驱动是否正确安装
- 使用 `nvidia-smi` 命令验证GPU状态

### Q: 训练速度很慢
**A**: 优化建议：
- 使用 `--no-realtime-vis` 禁用实时可视化
- 增加 `save_interval` 减少保存频率
- 检查数据加载是否为瓶颈
