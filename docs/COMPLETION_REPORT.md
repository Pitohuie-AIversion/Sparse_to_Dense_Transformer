## 🚀 功能演示步骤

### 1. 启动网站
```bash
cd docs
bundle install
bundle exec jekyll serve --host 0.0.0.0 --port 4000
```

### 2. 访问功能
- **英文版**: http://localhost:4000/Sparse_to_Dense_Transformer/
- **中文版**: http://localhost:4000/Sparse_to_Dense_Transformer/zh/

### 3. 体验功能
1. **多语言切换**: 点击右上角语言切换器
2. **主题切换**: 点击右下角主题按钮或按T键
3. **响应式测试**: 调整浏览器窗口大小
4. **链接验证**: 点击右下角🔍按钮验证链接
5. **键盘导航**: 使用Tab键和方向键导航
